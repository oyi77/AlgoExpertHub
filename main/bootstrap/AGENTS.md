# Bootstrap

## Purpose
Laravel application bootstrap -- creates the application instance and binds core interfaces (HTTP Kernel, Console Kernel, Exception Handler). This is the first code executed after autoloading, wiring the IoC container before any request handling begins.

## Key Files

| File | Purpose |
|------|---------|
| `app.php` | Creates `Illuminate\Foundation\Application`, binds singletons for HTTP Kernel (`App\Http\Kernel`), Console Kernel (`App\Console\Kernel`), and Exception Handler (`App\Exceptions\Handler`) |
| `cache/` | Bootstrap cache directory for compiled service providers and cached configuration |

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `cache/` | Compiled class file cache -- `services.php` and `packages.php` auto-generated by Laravel. Do not edit manually |

## For AI Agents

### Working In This Directory
- **Rarely needs modification** -- only change `app.php` if adding custom kernel bindings or changing the application base path
- The `cache/` directory is auto-managed by Laravel (`php artisan cache:clear`, `php artisan config:cache`)
- If bootstrap cache becomes stale or corrupted, delete files in `cache/` and re-run `php artisan config:cache`

### Common Patterns
- `app.php` follows standard Laravel bootstrap pattern -- singleton bindings for three core contracts
- `$_ENV['APP_BASE_PATH']` allows overriding the application root path
- The returned `$app` instance is consumed by `public/index.php` (web) and `artisan` (CLI)

## Dependencies

### Internal
- `app/Http/Kernel.php` -- Bound as HTTP kernel
- `app/Console/Kernel.php` -- Bound as console kernel
- `app/Exceptions/Handler.php` -- Bound as exception handler
- `config/` -- Configuration loaded during bootstrap

### External
- `laravel/framework` -- `Illuminate\Foundation\Application` class
- `vendor/autoload.php` -- Composer autoloader (loaded before bootstrap in entry points)
