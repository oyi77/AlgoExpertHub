# Specs-Driven Development (.sdd)

This directory contains the authoritative SDD (Specs-Driven Development) guidelines and templates for the AI Trading Platform.

## 🎯 Purpose

The .sdd directory serves as the single source of truth for all SDD-related configurations, templates, and guidelines across all AI tools in this project.

## 📁 Structure

- `guidelines.md` - Core SDD principles and workflow
- `templates/` - Standard templates for requirements, design, and tasks
- `specs/` - Active and archived specifications

## 🔄 Consistency

All AI tools (.kiro, .cursor, .qoder, .opencode, .trae) should reference and respect the guidelines in this directory to ensure consistent SDD practices across the platform.

## 📚 Usage

AI tools should:
1. Reference the guidelines in `guidelines.md` for SDD workflow
2. Use templates from the `templates/` directory for consistent documentation
3. Store active specs in `specs/active/` following the established structure
