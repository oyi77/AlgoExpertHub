# Spec: Bot Sales Landing Page

## ADDED Requirements

### Requirement: Marketing Layout
The Bot Sales landing page SHALL feature a modern, dark-themed, conversion-focused layout.

#### Scenario: Visual Elements
- **Given** the Bot Sales landing page is active
- **When** a user visits the homepage
- **Then** they SHALL see a high-impact hero section with a clear "Start Automated Trading" CTA
- **And** the page SHALL include a multi-exchange support visualization (logos of Binance, Bybit, etc.)
- **And** it SHALL display key features: Copy Trading, AI Algorithm, and Multi-Channel Signals

### Requirement: Responsive Design
The Bot Sales landing page SHALL be fully responsive, providing an optimal experience across mobile, tablet, and desktop devices.

#### Scenario: Mobile View
- **Given** the page is viewed on a mobile device (width < 768px)
- **Then** the hero section SHALL stack vertically
- **And** navigation SHALL be accessible via a hamburger menu
- **And** images SHALL be scaled appropriately for mobile performance
