# Qoder SDD Alignment

**ALIGNMENT WITH .SDD**: This configuration aligns with and references the authoritative SDD guidelines in `.sdd/guidelines.md`.

## Qoder Integration with SDD

Qoder should integrate with the SDD workflow as follows:

### Quest Generation
- Use `.sdd/templates/` for consistent quest documentation
- Follow the structure in `.sdd/guidelines.md` for quest breakdown
- Include clear acceptance criteria for each quest

### Repository Wiki Integration
- Link quests to relevant documentation in `repowiki/`
- Maintain consistency with SDD documentation standards
- Cross-reference with `.kiro/specs/` when applicable

### Best Practices
- Break down large quests into smaller, manageable tasks
- Ensure quests have clear success criteria
- Reference authoritative SDD guidelines for consistency
