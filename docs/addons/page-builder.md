## Getting Started

### Accessing Page Builder

1. Log in as **Admin**
2. Navigate to **Admin → Page Builder**
3. You'll see the Page Builder dashboard

### Quick Start (5 Minutes)

1. **Create Your First Page** - Click "Create Page"
2. **Choose a Template** - Select from pre-built templates
3. **Customize Content** - Drag and drop blocks
4. **Publish** - Make your page live

---

## Creating Pages

### New Page from Scratch

1. Click **Create Page**
2. Fill in basic information:
   - **Page Name**: Internal name (e.g., "About Us")
   - **URL Slug**: Public URL (e.g., "about" → yoursite.com/about)
   - **Page Title**: Browser title (for SEO)
   - **Meta Description**: Search engine description
3. Click **Create**
4. You'll be taken to the visual editor

### New Page from Template

1. Click **Create from Template**
2. Browse template library:
   - Landing Pages
   - About Us
   - Contact Us
   - FAQ
   - Pricing
   - Blog Post
   - Portfolio
3. Click **Use This Template**
4. Customize the template content
5. Save and publish

## Using the Visual Editor

### Editor Interface

The visual editor has three main areas:

#### 1. Block Library (Left Sidebar)
- Browse available blocks
- Drag blocks to canvas
- Search for specific blocks

#### 2. Canvas (Center)
- Visual preview of your page
- Drag and drop blocks
- Click to edit blocks
- Responsive preview (desktop/tablet/mobile)

#### 3. Settings Panel (Right Sidebar)
- Block settings
- Page settings
- Style options
- SEO settings

### Adding Blocks

**Method 1: Drag and Drop**
1. Find block in library
2. Drag to canvas
3. Drop where you want it
4. Blue line shows drop position

**Method 2: Click to Add**
1. Click block in library
2. Block added to bottom of page
3. Drag to reposition

### Editing Blocks

1. Click on any block
2. Settings panel opens on right
3. Edit content and settings
4. Changes appear instantly

### Moving Blocks

- **Drag**: Click and drag block to new position
- **Up/Down**: Use arrow buttons in block toolbar
- **Delete**: Click trash icon

### Duplicating Blocks

1. Hover over block
2. Click **Duplicate** icon
3. Copy appears below original

### Deleting Blocks

1. Hover over block
2. Click **Delete** icon (trash)
3. Confirm deletion

### Undo/Redo

- **Undo**: Ctrl+Z (Cmd+Z on Mac)
- **Redo**: Ctrl+Y (Cmd+Y on Mac)
- **Undo button**: Top toolbar

### Responsive Preview

Test how your page looks on different devices:

1. Click device icons in top toolbar:
   - 🖥️ **Desktop**: Full width
   - 📱 **Tablet**: 768px width
   - 📱 **Mobile**: 375px width
2. Adjust block settings per device
3. Hide blocks on specific devices

### Saving

- **Auto-save**: Every 30 seconds
- **Manual save**: Click "Save Draft"
- **Save indicator**: Shows last saved time

## SEO Optimization

### Page Title

- Appears in browser tab
- Shown in search results
- **Best practice**: 50-60 characters
- Include target keywords

**Example:**
```
About Us - AlgoExpertHub Trading Platform
```

### Meta Description

- Shown in search results
- Encourages clicks
- **Best practice**: 150-160 characters
- Include call-to-action

**Example:**
```
Learn about AlgoExpertHub, the leading trading signal platform. Join thousands of traders using our AI-powered signals. Start your free trial today!
```

### URL Slug

- Clean, readable URLs
- Include keywords
- Use hyphens, not underscores

**Good:**
```
yoursite.com/about-us
yoursite.com/pricing-plans
yoursite.com/contact
```

**Bad:**
```
yoursite.com/page?id=123
yoursite.com/about_us
yoursite.com/ABOUT-US
```

### Heading Structure

- One H1 per page (main heading)
- Use H2 for main sections
- Use H3-H6 for subsections
- Logical hierarchy

**Example:**
```
H1: About AlgoExpertHub
  H2: Our Mission
  H2: Our Team
    H3: Leadership
    H3: Developers
  H2: Contact Us
```

### Image Alt Text

- Describe image content
- Include keywords naturally
- Helps visually impaired users
- Improves SEO

**Example:**
```
Alt: "Trading dashboard showing real-time signals and analytics"
```

### Internal Linking

- Link to other pages on your site
- Use descriptive link text
- Helps SEO and navigation

**Good:**
```
Learn more about our [pricing plans](yoursite.com/pricing)
```

**Bad:**
```
Click [here](yoursite.com/pricing) for pricing
```

## Publishing Pages

### Draft vs Published

- **Draft**: Only visible to admins
- **Published**: Live on your website

### Publishing a Page

1. Complete your page design
2. Review in responsive preview
3. Check SEO settings
4. Click **Publish**
5. Page is now live

### Unpublishing a Page

1. Go to page list
2. Find your page
3. Click **Unpublish**
4. Page returns to draft status

### Setting Homepage

Make a page your site's homepage:

1. Edit page
2. Check **Set as Homepage**
3. Save
4. Page appears at yoursite.com/

### Preview Before Publishing

1. Click **Preview** button
2. Opens page in new tab
3. See exactly how it will look
4. Not visible to public

## Best Practices

### Design

1. **Consistent Branding**
   - Use same colors throughout
   - Consistent fonts
   - Matching button styles

2. **White Space**
   - Don't cram content
   - Use spacer blocks
   - Breathing room improves readability

3. **Visual Hierarchy**
   - Important content larger/bolder
   - Use headings properly
   - Guide user's eye

4. **Mobile-First**
   - Design for mobile first
   - Test on all devices
   - Hide non-essential content on mobile

5. **Fast Loading**
   - Optimize images (compress before upload)
   - Minimize custom code
   - Limit number of blocks

### Content

1. **Clear Headlines**
   - Descriptive, not clever
   - Include keywords
   - Promise value

2. **Scannable Text**
   - Short paragraphs
   - Bullet points
   - Subheadings

3. **Call-to-Action**
   - Every page should have a CTA
   - Clear what user should do next
   - Prominent button

4. **Proof Points**
   - Testimonials
   - Statistics
   - Trust badges

### SEO

1. **Unique Titles**
   - Different title for each page
   - Include keywords
   - 50-60 characters

2. **Compelling Descriptions**
   - Unique for each page
   - Include call-to-action
   - 150-160 characters

3. **Header Tags**
   - One H1 per page
   - Logical hierarchy
   - Include keywords

4. **Image Optimization**
   - Descriptive alt text
   - Compress images
   - Appropriate file names

## Troubleshooting

### Editor Not Loading

**Problem**: Visual editor shows blank screen

**Solutions:**
- Clear browser cache
- Try different browser
- Disable browser extensions
- Check JavaScript is enabled
- Contact support if persists

### Changes Not Saving

**Problem**: Edits disappear after refresh

**Solutions:**
- Check internet connection
- Look for save error messages
- Try manual save (Ctrl+S)
- Check browser console for errors
- Ensure not in private/incognito mode

### Images Not Uploading

**Problem**: Image upload fails

**Solutions:**
- Check file size (max 5MB)
- Verify file type (JPG, PNG, GIF, SVG)
- Compress image before upload
- Check internet connection
- Try different image

### Page Not Showing

**Problem**: Published page returns 404

**Solutions:**
- Verify page is published (not draft)
- Check URL slug is correct
- Clear site cache
- Check for duplicate slugs
- Verify theme is active

### Responsive Issues

**Problem**: Page looks broken on mobile

**Solutions:**
- Use responsive preview in editor
- Check column settings (stack on mobile)
- Reduce font sizes for mobile
- Hide non-essential blocks on mobile
- Test on real device

## FAQ

**Q: Can I edit the HTML/CSS directly?**
A: Yes, use the HTML block for custom code. Advanced users can also edit theme files.

**Q: How many pages can I create?**
A: Unlimited pages.

**Q: Can I password-protect pages?**
A: Not currently. Feature planned for future release.

**Q: Can I schedule page publishing?**
A: Not currently. Publish manually when ready.

**Q: Are pages mobile-responsive automatically?**
A: Yes, but you should test and adjust for best results.

**Q: Can I export pages?**
A: Not currently. Pages stored in database.

**Q: Can I use custom fonts?**
A: Yes, via custom CSS or Google Fonts integration.

**Q: How do I delete a page?**
A: Go to page list, click delete icon, confirm.
